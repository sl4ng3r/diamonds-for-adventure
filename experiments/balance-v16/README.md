# V16 – zwei tiefe Höhlenversuche (verworfen)

V16 ist eine unveröffentlichte Forschungsvariante. Sie verwendet acht horizontale Richtungsreihenfolgen inklusive Umkehrungen, zwei tiefe Höhlenversuche in Y=-64..-33, einen mittleren Versuch in Y=-32..-1 und eine obere Regel mit `scatter_chance: 0`.

Die 20 Kalibriergebiete ergaben 58 gegenüber 23 Vanilla-Luftkontaktgruppen (252,2 %). Y=-57 lag bei 21 gegenüber 118 eingeschlossenen Erzblöcken (17,8 %). Der obere Durchlauf wurde durch `scatter_chance: 0` nicht zuverlässig deaktiviert; 30 luftberührte Kandidatenblöcke lagen im Band Y=0..16. V16 ist deshalb verworfen. Ergebnisse: `summary.json`, `profiles.json`.
