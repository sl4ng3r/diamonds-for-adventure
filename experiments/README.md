# Forschungsvarianten

Der aktuelle Checkout enthält nur die für den gegenwärtigen Teststand relevanten Varianten V24 bis V26. V26 ist das derzeitige, **nicht freigegebene** Testpaket; die zugehörige `cave-diamonds-v26-test.mcpack` wird bewusst mitversioniert, damit sie auf einem anderen Rechner nach `git pull` verfügbar ist.

Die früheren Varianten V1 bis V19 wurden aus dem aktuellen Verzeichnis entfernt, um Checkouts übersichtlich zu halten. Ihre Ergebnisse sind in `AGENTS.md` und `TESTREPORT.md` zusammengefasst; die damaligen Rohdateien lassen sich bei Bedarf aus Commit `2ba1fde` abrufen.

V24 und V25 bleiben erhalten, weil sie die Vergleichsbasis und den unabhängigen Holdout für die aktuelle Kalibrierung enthalten. Sie sind ebenfalls keine freigegebenen Realm-Pakete.
