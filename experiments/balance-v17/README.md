# V17 – obere Regel mit Chance null (verworfen)

V17 ist eine unveröffentlichte Forschungsvariante. Sie nutzt acht horizontale Richtungsreihenfolgen, einen tiefen und einen mittleren Höhlenversuch sowie `scatter_chance: 0` für die obere Regel.

In 20 Kalibriergebieten entstanden 42 gegenüber 23 Vanilla-Luftkontaktgruppen (182,6 %). Y=-57 lag bei 21 gegenüber 118 Blöcken (17,8 %). Das obere Band enthielt weiterhin 30 luftberührte Kandidatenblöcke. Der Bedrock-Server behandelt `scatter_chance: 0` hier offenbar nicht als zuverlässiges Ausschalten. V17 ist verworfen. Ergebnisse: `summary.json`, `profiles.json`.
